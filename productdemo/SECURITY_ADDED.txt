Create Product (Admin Only):
  $ curl -X POST http://localhost:8080/api/products \
    -u admin:admin123 \
    -H "Content-Type: application/json" \
    -d '{"name":"Laptop","price":999.99,"quantity":5}'

Get Product (Any User):
  $ curl -X GET http://localhost:8080/api/products/1 \
    -u user:user123

Test Unauthorized (Will fail with 401):
  $ curl -X POST http://localhost:8080/api/products \
    -H "Content-Type: application/json" \
    -d '{"name":"Item","price":100,"quantity":5}'

Test Forbidden (User trying to create - Will fail with 403):
  $ curl -X POST http://localhost:8080/api/products \
    -u user:user123 \
    -H "Content-Type: application/json" \
    -d '{"name":"Item","price":100,"quantity":5}'

Test Validation (Invalid price - Will fail with 400):
  $ curl -X POST http://localhost:8080/api/products \
    -u admin:admin123 \
    -H "Content-Type: application/json" \
    -d '{"name":"Item","price":-50,"quantity":5}'
