## ⚡ 10-Minute Activation

### Step 1: Create SonarCloud Account (2 min)
```
URL: https://sonarcloud.io
Sign up with GitHub
```

### Step 2: Generate Token (3 min)
```
My Account → Security → Generate Tokens
Name: Vernfix_productdemo
Copy token
```

### Step 3: Add GitHub Secret (3 min)
```
Repo Settings → Secrets → New secret
Name: SONAR_TOKEN
Value: [paste token]
```

### Step 4: Deploy (2 min)
```bash
git add .
git commit -m "Add SonarQube integration"
git push origin main
```
